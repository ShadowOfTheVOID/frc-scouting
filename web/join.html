IF A PHONE CAN'T CONNECT
  • Make sure it's on the same wifi as this laptop. Not a different venue SSID, not cellular.
  • Captive portal: open any ordinary website on the phone first and accept whatever it asks, then try again.
  • Windows: allow Python through Windows Firewall on Private networks. It prompts the first time and silently blocks everything if dismissed.
  • If it reaches the internet but not this laptop, the network is isolating clients from each other — common on venue and guest wifi, and nothing here can defeat it. Scout offline and import the phones' backup files afterwards; nothing is lost.
  • Do not switch on this laptop's hotspot to get around it. Team access points aren't allowed in the venue and the FTA will have you shut it off.
